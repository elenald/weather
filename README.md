# Погода

Веб-приложение с прогнозом погоды. По умолчанию открывается **Ликино-Дулёво**, но можно найти любой город мира.

## Возможности

- текущая погода: температура, «ощущается как», влажность, ветер и порывы, давление, осадки, УФ-индекс;
- почасовой прогноз на 24 часа;
- прогноз на 7 дней с диапазоном температур и вероятностью осадков;
- поиск городов с подсказками, управление с клавиатуры;
- определение местоположения по геолокации;
- переключение °C / °F;
- запоминание последнего города, недавних запросов и выбранных единиц;
- адаптивная вёрстка и фон, который меняется в зависимости от погоды и времени суток.

## Запуск

Приложению не нужна сборка и API-ключи. Достаточно открыть `index.html` в браузере.

Для корректной работы геолокации и некоторых браузерных функций лучше запустить локальный сервер:

```bash
python -m http.server 8000
```

Затем открыть [http://localhost:8000](http://localhost:8000).

## Данные

- [Open-Meteo](https://open-meteo.com) — основной источник прогноза и поиск городов.
- [MET Norway](https://www.met.no) — резервный источник прогноза. Если `api.open-meteo.com` недоступен (блокировка, сбой, таймаут), приложение автоматически переключается на MET Norway и запоминает это на 6 часов.
- [BigDataCloud](https://www.bigdatacloud.com) — обратное геокодирование при определении местоположения (при недоступности используется подпись «Моё местоположение»).

В резервном режиме часть показателей недоступна и отображается как «—»: вероятность осадков и УФ-индекс. Остальные значения (температура, «ощущается как», влажность, точка росы, ветер, давление, восход и закат) рассчитываются или берутся из MET Norway.

## Структура

```
index.html   — разметка страницы
styles.css   — оформление, адаптивность, темы погоды
app.js       — загрузка данных, поиск, рендер, localStorage
```

## Настройка города по умолчанию

В `app.js` найдите `DEFAULT_PLACE` и измените название, координаты и часовой пояс:

```js
const DEFAULT_PLACE = {
  name: 'Ликино-Дулёво',
  admin1: 'Московская область',
  country: 'Россия',
  latitude: 55.7078,
  longitude: 38.9572,
  timezone: 'Europe/Moscow',
};
```

Этот город показывается при первом запуске. Если пользователь уже выбирал город, приложение откроет его — последний выбор хранится в `localStorage`.
